## Available Tools

### Compliance Requirements

| Tool | Description |
|------|-------------|
|  | Add a compliance tracking item |
|  | Retrieve a requirement by ID |
|  | Search by title or description |
|  | Update a requirement |

### Risk Register

| Tool | Description |
|------|-------------|
|  | Add a risk to the risk register |
|  | Retrieve a risk by ID |
|  | Search by title or description |
|  | Update a risk |
|  | Delete a risk by ID |

### Compliance & Risk Reporting

| Tool | Description |
|------|-------------|
|  | List all requirements |
|  | List all risks |
|  | Count risks by level |
|  | Breached/non-compliant items |
|  | Requirements past notice deadline |
|  | Overall compliance status |
