## Available Tools

### Asset Management

| Tool | Description |
|------|-------------|
|  | Add an asset with type, serial, model, quantity |
|  | Retrieve an asset by ID |
|  | Search by type, description, serial, or tag |
|  | Update an asset |
|  | Delete an asset by ID |
|  | List all assets |
|  | Total asset count |

### Status & Reporting

| Tool | Description |
|------|-------------|
|  | Filter by status |
|  | Filter by type |
|  | Assets with quantity < 5 |
|  | Warranty expiring within N days |
|  | Assets by status as text resource |

### Infrastructure

| Tool | Description |
|------|-------------|
|  | Force pending writes |
|  | Create timestamped backup |
|  | List backups, newest first |
|  | Restore from backup |
