## Available Tools

### Maintenance Requests

| Tool | Description |
|------|-------------|
|  | Create a maintenance request |
|  | Retrieve a request by ID |
|  | Search by title or location |
|  | Update a request |
|  | Mark a request as closed |
|  | Delete a request by ID |
|  | List all requests, sorted by date |
|  | Open/in-progress requests |
|  | Filter by priority |
|  | Requests past due date |

### Work Orders

| Tool | Description |
|------|-------------|
|  | Create a work order |
|  | Retrieve a work order by ID |
|  | Complete a work order |

### Space Management

| Tool | Description |
|------|-------------|
|  | Add a workspace / room |
|  | Retrieve a space by ID |
|  | Delete a space by ID |

### Maintenance Schedules

| Tool | Description |
|------|-------------|
|  | Add a recurring schedule |

### Reporting

| Tool | Description |
|------|-------------|
|  | Maintenance dashboard |
|  | Space counts |
|  | List all spaces |

### Infrastructure
| Tool | Description |
|------|-------------|
|  | Force pending writes |
|  | Create timestamped backup |
|  | List backups, newest first |
|  | Restore from backup |
