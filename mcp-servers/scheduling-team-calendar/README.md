## Available Tools

### Calendar Management

| Tool | Description |
|------|-------------|
|  | Add a team resource calendar |
|  | Retrieve a calendar by ID |

### Booking & Scheduling

| Tool | Description |
|------|-------------|
|  | Add a slot definition |
|  | Add a booking (single or recurring) |
|  | Retrieve a booking by ID |
|  | Search by title or description |
|  | Update a booking |
|  | Delete a booking |
|  | List all bookings, sorted by date |
|  | Bookings for a specific calendar |

### Availability & Capacity

| Tool | Description |
|------|-------------|
|  | Get free slots for a calendar in range |
|  | Calendar counts for overload check |
|  | Total booking count |

### Infrastructure
| Tool | Description |
|------|-------------|

|  | Create timestamped backup |
