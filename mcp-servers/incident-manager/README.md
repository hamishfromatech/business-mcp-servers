## Available Tools

### Ticket Management

| Tool | Description |
|------|-------------|
|  | Create a new incident ticket |
|  | Retrieve an incident by ID |
|  | Search by title or description |
|  | Update an incident |
|  | Delete an incident by ID |
|  | List all incidents, sorted by date |
|  | Total incident count |

### Escalation & Lifecycle

| Tool | Description |
|------|-------------|
|  | Escalate an incident with level tracking |
|  | Close an incident, recording resolution |

### SL & Reporting

| Tool | Description |
|------|-------------|
|  | Incidents with status open/in-progress |
|  | Filter by status |
|  | Incidents exceeding SLA hours |
|  | % of resolved tickets meeting SLA |

### Infrastructure
| Tool | Description |
|------|-------------|
